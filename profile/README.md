# Katakate

Sandbox, fork, rewind, fast-forward. MicroVMs, pods, clusters.

[k7](https://github.com/Katakate/k7) is self-hosted VM sandboxes for untrusted code. CLI, API, and Python SDK. [k7d](https://github.com/Katakate/k7d) is the microVM runtime inside it: warm fork of a live VM, or a whole Kubernetes cluster.

[k7](https://github.com/Katakate/k7) · [k7d](https://github.com/Katakate/k7d) · [docs](https://k7d.org)
